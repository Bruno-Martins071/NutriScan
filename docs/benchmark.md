1° Yuka  

O Yuka é um aplicativo gratuito para dispositivos móveis que permite escanear o código de barras de alimentos e cosméticos para analisar sua composição e avaliar o impacto deles na saúde. Principais funcionalidades 

Escaneamento de código de barras. 

Avaliação da qualidade nutricional dos produtos. 

Exibição de informações sobre ingredientes. 

Sugestão de alternativas mais saudáveis. 


Pontos positivos 

Interface simples e intuitiva. 

Resultado exibido rapidamente após o escaneamento. 

Avaliação visual fácil de compreender. 


Pontos negativos 

Foco maior em qualidade nutricional do que em alergênicos. 

Algumas informações dependem da atualização da base de dados. 

Funcionalidades avançadas limitadas em alguns países. 


Aspectos de interface/experiência 


Uso de cores para indicar qualidade do produto. 

Layout limpo e organizado. 

Navegação simples para usuários iniciantes. 

O que pode ser aproveitado ou melhorado 

Aproveitar a simplicidade da interface. 

Utilizar feedback visual imediato. 

Melhorar o foco específico em alergias e intolerâncias alimentares. 

 

2° Open	Food Facts  

O Open Food Facts é um banco de dados global, gratuito e colaborativo sobre produtos alimentícios, frequentemente apelidado de "Wikipedia da comida". Criado por uma organização sem fins lucrativos, o projeto funciona como uma plataforma de dados abertos, permitindo que qualquer pessoa consulte, adicione ou reutilize as informações para qualquer finalidade.  


Principais funcionalidades 

Consulta colaborativa de produtos alimentícios. 

Escaneamento de código de barras. 

Exibição de ingredientes e informações nutricionais. 

Identificação de alergênicos presentes no produto. 


Pontos positivos 

Base de dados extensa e gratuita. 

Grande quantidade de produtos cadastrados. 

Transparência das informações. 


Pontos negativos 


Dados dependem da colaboração dos usuários. 

Algumas informações podem estar incompletas. 

Interface pode parecer complexa para usuários leigos. 

Aspectos de interface/experiência 

Grande quantidade de informações na mesma tela. 

Foco informativo em vez de visual. 

Processo de consulta relativamente rápido. 

O que pode ser aproveitado ou melhorado 

Aproveitar a riqueza dos dados cadastrados. 

Simplificar a apresentação das informações. 

Destacar melhor os alergênicos críticos. 
 

3° Spoonful  

O Spoonful é um aplicativo de escaneamento de alimentos projetado para ajudar pessoas com restrições alimentares e dietas especiais a fazer compras no supermercado com mais segurança e rapidez. 

Principais funcionalidades 

Escaneamento de código de barras. 

Identificação de alergênicos e ingredientes. 

Perfil personalizado de restrições alimentares. 

Alertas automáticos para ingredientes perigosos. 

Pontos positivos 

Foco específico em alergias alimentares. 

Alertas claros e rápidos. 

Cadastro detalhado das restrições do usuário. 

Pontos negativos 

Algumas funcionalidades dependem de assinatura. 

Base de produtos mais forte em alguns países do que em outros. 

Aspectos de interface/experiência 

Interface simples e objetiva. 

Uso de cores para comunicar riscos. 

Processo de escaneamento rápido. 

O que pode ser aproveitado ou melhorado 

Personalização do perfil de alergias. 

Sistema de alertas instantâneos. 

Melhorar o funcionamento offline.
